# Spektrogram

## Last ned

Klikk **Code → Download ZIP** øverst på denne siden, og pakk ut mappen.

Eller med git:

```
git clone https://github.com/duckrice/fouriertransformasjonMM2.git
```

## Kjør

Krever Python 3 med numpy og matplotlib.

**Windows:**

```
py -m pip install numpy matplotlib
py spektrogram.py
```

**macOS / Linux:**

```
python3 -m pip install numpy matplotlib
python3 spektrogram.py
```

Opptaket `opptak_piano.wav` ligger under **Examples → Recording (piano)**.
